Art: manga | Tone: action | Layout: character reference sheet | Aspect: 4:3

## Generation Prompt

Create an original character reference sheet for Xiaolin, a fictional website
resident, using hard-edged black-and-white Japanese martial-arts manga visual
grammar without imitating any named artist or copyrighted franchise.

Four consistent views of the same adult character: front, three-quarter, side,
and full-body action stance. Include four small facial-expression studies:
neutral observation, intense concentration, puzzled release, quiet reflection.
Xiaolin has short slightly wavy black hair with one loose forelock, round dark
glasses, a narrow oval face, compact ordinary build, teal overshirt worn open
over a white T-shirt, dark straight trousers, low canvas shoes, and a small
orange notebook.

Use bold variable ink contours, dense cross-hatching, dry-brush shadows,
visible paper grain, grounded anatomy, and a restrained deep-red spot color
only on the orange notebook. White background with clear separation between
poses. No labels, readable text, speech bubbles, logos, watermarks, gore,
existing manga characters, artist signatures, or resemblance to a real person.
